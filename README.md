# KodeKloud DevOps Pro Specialization Practice Repository

This repository is my hands-on proof of practice for the **KodeKloud DevOps Pro: Linux, Docker, Kubernetes, CI/CD & IaC Specialization** (Coursera), taught by **Mumshad Mannambeth**.

I use this repo to track labs, exercises, and project deliverables from all five courses in the specialization. Each course has its own directory so progress and artifacts stay organized.

## Specialization Focus

Over this 5-course series, I practice and document skills across:

- Linux administration, hardening, and automation
- Source control and CI/CD with Git and Jenkins
- Containerization with Docker and Docker Compose
- Kubernetes orchestration for production-like workloads
- Infrastructure as Code (IaC) with Terraform and Ansible on AWS

## Repository Structure

- `01-devops-foundation-linux-systems/`
- `02-source-control-cicd/`
- `03-mastering-docker-containers/`
- `04-kubernetes-orchestration/`
- `05-infrastructure-automation-iac/`

Each directory contains a dedicated README explaining what will be stored there.
